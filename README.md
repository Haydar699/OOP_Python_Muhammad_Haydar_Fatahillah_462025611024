# Sistem Administrasi Rumah Sakit Yasyfin

Final Project Object-Oriented Programming.

## Deskripsi

Sistem Administrasi Rumah Sakit Yasyfin merupakan aplikasi sederhana
berbasis terminal yang digunakan untuk mengelola data pasien, dokter,
rekam medis, jadwal dokter, dan pembayaran.

Project ini dibuat untuk menerapkan konsep Object-Oriented Programming
yang telah dipelajari selama satu semester.

## Konsep OOP

Project ini menerapkan:

- Class dan Object
- Inheritance
- Encapsulation
- Polymorphism
- Magic Method
- Instance Method
- Static Method
- Exception Handling
- Custom Exception
